# Stellar Technical Services

A polished, responsive single-page website concept for water treatment, nanobubble pool technology, and scent diffuser systems.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Use `npm run build` to create a production build and `npm start` to serve it.

All company details and imagery are demo placeholders. The inquiry form provides local confirmation only; connect a form service before launch. Replace demo contact details, imagery, and branding with approved client assets before deployment.
